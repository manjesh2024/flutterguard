# Documentation

The repository keeps the full guide in `docs/` so the project layout matches the FlutterGuard source tree. pub.dev expects a singular `doc/` directory, so this file is the package entry and `docs/` is omitted from the published archive.

Start with the repository:

https://github.com/manjesh2024/flutterguard/tree/main/docs

That tree includes the architecture, audit modules, rule catalogue, configuration reference, severity policy, baseline and suppression, auto-fix safety, report formats, CI, custom rules, contributing, and publishing guides.
