# Example configuration

This directory is a sample `.flutterguard.yaml` for a Flutter app. It is not itself a Flutter application.

Copy `example/flutterguard.yaml` to the root of an app as `.flutterguard.yaml`, or run `flutterguard init` in that app.

Then:

```bash
flutterguard
```

Reports are written to `build/flutterguard/` inside the app.
